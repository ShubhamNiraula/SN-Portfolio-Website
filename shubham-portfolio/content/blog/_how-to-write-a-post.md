HOW TO WRITE A BLOG POST
========================

(This file starts with "_", so it is NOT shown on the website.)

1. Make a new file in this folder (content/blog/).
   Name it with small letters and dashes, e.g.  my-arctic-summer.md
   The name becomes the web address:  shubhamniraula.com.np/blog/my-arctic-summer/

2. Start the file with this header (between the --- lines):

---
title: My summer in the Arctic
date: 2026-11-30
lang: en
summary: One or two sentences that appear on the blog card.
draft: false
---

   - lang:  en  for English, ru  for Russian
   - draft: true  hides the post from the list (to finish later)

3. Write the post below the header. You can use:

# A heading
## A smaller heading
A normal paragraph. **bold text**, *italic text*.
[a link](https://news.itmo.ru)
![a picture](/blog/my-photo.jpg)     <- put pictures in the public/blog/ folder
- a bullet point
1. a numbered point
> a quote

4. Upload the file to GitHub. The website updates by itself in 2–3 minutes.
